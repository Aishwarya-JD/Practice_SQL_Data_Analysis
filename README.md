A structured, topic-wise collection of SQL scripts progressing from foundational database operations to advanced analytical querying, real-world data aggregation, and business intelligence reporting. 

This repository contains practical solutions based on realistic datasets, including food delivery platform metrics (**Swiggy**) and enterprise organizational data (**Company DB**).
